ABOUT ME & PROJECT

안녕하세요, 독서모임의 지속 가능성을 연구합니다

다양한 플랫폼에서 회원을 모으고 이끄는 독서모임 관리자들의 수고를 덜고,
회원들과 언제나 솔직하고 투명하게 소통할 수 있는 테크 솔루션을 설계합니다.

🎯

방문자: 누구를 위한 사이트인가요?

매주 여러 플랫폼(소모임, 당근, 인스타, 에브리타임)을 넘나들며 회원 명단을 정리하고, 복사-붙여넣기로 공지를 올리느라 지친 독서모임 호스트와 운영진을 위한 공간입니다.

💡

핵심 메시지: 투명한 소통

공지와 회비 내역, 출석 기록이 투명하게 공유될 때 회원은 소속감과 신뢰를 느낍니다. 운영자의 수고는 줄이되, 정보는 더 정직하고 맑게 흐르는 커뮤니티 문화를 지향합니다.

🚀

해결하고자 하는 문제

플랫폼마다 다른 글자수 규격과 공지 누락, 그리고 비효율적인 수기 엑셀 관리 문제를 웹 자동화와 구글 시트 데이터 파이프라인으로 해결합니다.

CORE VALUE

우리가 추구하는 '투명한 소통' 3원칙

단순한 정보 전달을 넘어, 모임 운영의 신뢰를 쌓는 3가지 기준

01

채널 간 정보 비대칭 제로

인스타로 들어온 회원도, 당근이나 카톡으로 들어온 회원도 소외되지 않도록 모든 공지가 동시·동일하게 배포됩니다.

02

누구나 납득하는 데이터 공유

출석 현황, 모임 회비, 읽은 책 아카이브가 구글 시트와 연동되어 관리자와 회원 모두에게 맑게 공개됩니다.

03

운영진의 과부하 방지

소통이 투명해지려면 운영자가 지치지 않아야 합니다. 반복 업무를 자동화하여 책과 대화에 집중할 시간을 선물합니다.

INTEREST AREAS

관심 연구 및 기술 분야

모임 문화와 기술의 접점을 고민하는 핵심 관심사입니다.

자동화 & API

멀티채널 자동 배포 아키텍처

웹훅(Webhook) 및 각 소셜 플랫폼 API를 연계하여 한 번의 마크다운 작성으로 채널별 최적 포맷을 생성하는 시스템을 연구합니다.

데이터 관리

Google Workspace & 시트 연동

별도의 무거운 서버나 복잡한 관리자 페이지 없이도, 누구나 친숙한 구글 시트를 DB로 활용하는 가벼운 노코드/로우코드 데이터 설계에 관심이 있습니다.

  • ✔ 6대 플랫폼(카톡, 소모임, 당근, 인스타, 에타, 네이버) 서식 변환

  • ✔ 모바일 환경에서도 가로 스크롤 없이 최적화된 반응형 UI
준비 중 (차기 개발) Google Sheets API · Kakao Webhook

실제 구글 시트 실시간 양방향 OAuth 연동

관리자의 실제 구글 드라이브 시트 URL을 입력하면 자동으로 출석부와 회비 장부가 동기화되는 OAuth2 기반의 실시간 데이터 연동 기능을 준비 중입니다.

  • ⏳ 구글 서비스 계정(Service Account)을 활용한 읽기/쓰기 자동화
  • ⏳ 카카오톡 오픈채팅방 웹훅 알림 자동 발송 연계
