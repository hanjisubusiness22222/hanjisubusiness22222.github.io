## 2. 핵심 기능 안내 (3-Step Workflow)

### 💬 STEP 1. 카카오톡 단체방 공지 자동화 (Kakao Notice Composer)
- **주말 일정 원클릭 자동 계산**:
  - `⚡ 이번 주말 (토·일)`: 현재 날짜 기준으로 이번 주 토요일과 일요일 날짜를 자동 계산하여 템플릿에 즉시 반영
  - `📅 다음 주말 (토·일)`: 다음 주말 일정을 즉시 계산하여 한 번의 클릭으로 공지 생성
- **커스텀 파라미터 연동**:
  - 독서모임 신청 페이지 링크(Streamlit 데모 등) 및 1:1 오픈채팅 프로필 링크 자유 입력 및 치환
- **실제 카카오톡 모바일 뷰어 (Live Mockup)**:
  - 스마트폰 상단 상태바, 현재 실시간 시계 연동
  - 톡게시판 상단 핀 공지 바 (`📌 [10/03, 04] 모임신청 안내`)
  - 노란 말풍선 본문 내 하이퍼링크 자동 변환 및 글자 수 카운터
  - 하단 모임 신청 / 1:1 문의 바로가기 액션 버튼
- **스마트 브리지**:
  - `📋 카톡 공지문 전체 복사`: 클릭 한 번으로 서식 유지 클립보드 복사
  - `💬 카카오톡 열기`: PC/모바일 카카오톡 앱 즉시 연결

---

### 📝 STEP 2. 네이버 카페 공지 (SmartEditor Bridge)
- **카페 맞춤형 서식 자동 빌더**:
  - 모임 요일 간편 선택 (`토요일` / `일요일`)
  - 정기 모임 장소 입력(강남 스터디룸 등) 및 공지 본문 자동 포맷팅
  - 독서모임 기본 서식(일시, 준비물, 자유책 소개 방식, 신청 방법 등) 프리셋 지원
- **네이버 스마트에디터 ONE 서식 미리보기**:
  - 카페 본문 스타일(헤더 포인트 라인, 폰트 스타일, 하이퍼링크)을 동일하게 시뮬레이션
- **스마트에디터 복사 브리지**:
  - `📝 스마트에디터 서식 원클릭 복사`: `ClipboardItem`을 활용하여 HTML 서식과 텍스트를 동시에 클립보드에 저장 (네이버 카페 글쓰기 창에 `Ctrl+V` 시 서식과 링크가 그대로 유지)
  - `🟢 네이버 카페 글쓰기 창 즉시 열기`: 공식 네이버 카페 글쓰기 페이지로 안전하게 새 창 이동

---

### 📊 STEP 3. 독서모임 회원 목록 (Google Sheets Integration)
- **공식 구글 스프레드시트 실시간 연동**:
  - 실제 운영 중인 구글 스프레드시트(`1i6zZuk5ii6VotMiYPdHSQOFzpht2JTUgOuDrRoXcZh8`)를 공식 `htmlembed` 위젯으로 내장
  - Google Drive 클라우드 자동 동기화 상태 인디케이터 표시
- **편의 도구**:
  - `📋 시트 주소 복사`: 회원 목록 시트의 URL을 클립보드에 복사
  - `🔄 시트 새로고침`: 시트 프레임을 재로드하여 최신 편집 내역 즉시 반영
  - `📊 회원 목록 원본 새 창에서 열기 / 편집 ↗`: 권한이 있는 관리자가 전체 시트 화면에서 대량 수정 및 필터를 사용할 수 있도록 공식 에디터 연결

## 3. 보안 및 안정성 검증 (Security & Reliability)

본 프로젝트는 운영 관리자의 보안과 시스템 안정성을 최우선으로 설계되었습니다.

1. **계정 자격증명 및 개인정보 유출 위험 Zero**:
   - 네이버/카카오 비밀번호나 개인 API 키를 서버나 브라우저에 저장하지 않으며, 클립보드 브리지를 통해 안전하게 전달합니다.
   - 소스코드 및 형상관리(Git) 내에 비밀번호, 토큰, 회원 개인 식별 정보(PII)가 일절 존재하지 않습니다.
2. **XSS (크로스 사이트 스크립팅) 차단**:
   - 공지 본문 렌더링 시 `escapeHtml()` 필터를 통해 특수문자(`<`, `>`, `&`, `"`, `'`)를 철저히 이스케이프하여 스크립트 인젝션을 원천 차단합니다.
3. **역탭내빙 (Reverse Tabnabbing) 방지**:
   - 새 창으로 열리는 모든 외부 링크(`target="_blank"`)에 `rel="noopener noreferrer"` 속성을 적용하여 부모 창 객체 조작 및 피싱 위협을 방지합니다.
4. **전 구간 HTTPS 암호화 & 무서버 아키텍처**:
   - GitHub Pages의 전송 계층 암호화(TLS/HTTPS)로 안전하게 서비스되며, 별도의 백엔드 데몬 없이 구동되므로 서버 장애 위험 없이 24시간 무중단 구동됩니다.

## 4. 프로젝트 파일 구조

```text
├── index.html            # 시맨틱 구조 기반의 관리자 웹 콘솔 마크업 (카톡/카페/시트)
├── style.css             # 모던 프리미엄 다크/라이트 테마, 카톡 모바일 목업, 반응형 CSS
├── app.js                # 주말 자동 계산, XSS 방지, 클립보드 브리지, 시트 새로고침 로직
├── index_all_in_one.html # 단일 파일 배포 및 오프라인 열람용 번들
└── README.md             # 프로젝트 기획, 기능 명세 및 시스템 안내서
```

## 6. 향후 고도화 로드맵 (추가 및 개선 권장 기능)

본 프로젝트는 운영 효율성을 극대화하기 위해 다음과 같은 기능 고도화 및 사용성 개선을 추천합니다.

### 💡 앞으로 추가하면 좋을 기능 (New Features)
1. **모임 일정 캘린더 연동 (Google Calendar / iCal / 카카오 캘린더)**
   - 생성된 주말 모임 일정(일시, 장소, 준비물)을 클릭 한 번으로 개인 구글 캘린더나 애플 캘린더에 등록할 수 있는 `.ics` 파일 다운로드 및 캘린더 딥링크 기능 추가.
2. **다양한 모임 유형별 커스텀 템플릿 프리셋 관리**
   - 현재의 '자유 도서 모임' 외에도 '지정 도서 토론 모임(발제문 질문 리스트 첨부)', '시즌제 독서 정모', '온라인 북클럽(Zoom/Discord)', '번개 모임' 등 다양한 양식을 저장하고 필요할 때 불러올 수 있는 프리셋 매니저.
3. **구글 시트 API 연동 실시간 통계 요약 대시보드 (KPI Cards)**
   - Iframe 임베드 조회 방식에서 한 걸음 더 나아가, Google Sheets v4 API(또는 Apps Script Webhook)를 통해 '이번 주 참석 인원 수', '회비 납부 완료율(%)', '발제문 미제출자 수'를 상단 통계 카드 형태로 실시간 요약 제공.
4. **인스타그램 & 카카오톡 홍보용 카드뉴스 자동 생성기 (Canvas Generator)**
   - 모임 일시, 장소, 추천 도서명을 입력하면 인스타그램 피드/스토리 및 카카오톡 단톡방 공유에 최적화된 1:1 정방형 그래픽 배너 이미지를 HTML5 Canvas를 통해 원클릭으로 렌더링하고 다운로드하는 기능.

---

### 🛠️ 앞으로 개선 및 수정하면 좋을 기능 (Improvements & Optimization)
1. **모바일 최적화 PWA (Progressive Web App) 도입**
   - 모바일 브라우저에서도 홈 화면에 'BookLink 관리자' 아이콘을 추가하여 네이티브 앱처럼 실행하고 빠르게 공지문을 복사할 수 있도록 웹앱 매니페스트(`manifest.json`) 및 서비스 워커(Service Worker) 적용.
2. **카카오톡 공유 공식 JavaScript SDK 연동**
   - 현재의 클립보드 복사 브리지 방식에 더하여, Kakao JavaScript SDK를 활용한 `카카오톡 공유하기(메시지 전송)` 버튼을 도입하여 관리자가 단톡방을 찾아 붙여넣지 않고도 대화방으로 바로 전송할 수 있는 경로 추가.
3. **모바일 해상도 맞춤형 시트 뷰어 가독성 개선**
   - 스마트폰 등 좁은 화면에서 구글 시트를 조회할 때 가로 스크롤로 인한 불편을 줄이기 위해, 모바일 화면에서는 자동 축소 배율(CSS Transform Scale)을 적용하거나 핵심 정보만 요약해 보여주는 모바일 전용 뷰 토글 추가.
4. **다크 모드 / 라이트 모드 테마 스위처**
   - 늦은 밤이나 저녁 시간대에 주로 공지를 작성하는 모임 호스트의 눈 피로도를 낮추기 위해 헤더 영역에 다크 모드 토글 스위치 제공.
