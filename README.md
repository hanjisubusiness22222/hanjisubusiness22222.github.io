## 1. 목적
독서 모임 운영진이 반복되는 업무를 편하게 수행할 수 있도록 관리자용 페이지를 만들었습니다. 주요 기능은 세 가지로 공지기능, 회원명단 확인 기능, 회계장부 대시보드 및 확인 기능입니다.
먼저 공지 기능은 정기적으로 모임 공지를 카카오톡과 네이버 카페를 통해 하는데 반복되는 업무를 최대한 줄일 수 있도록 공지사항을 템플릿으로 작성하여 간편하게 해당 페이지에 접속하여 공지할 수 있는 기능을 넣었습니다.
그 외 회원가입과 회비입금 및 환불이 수시로 진행되고 있는데 이를 실시간으로 확인하고 수정하기 편하게 연동된 구글 시트를 통해 관리할 수 있도록 기능을 넣었습니다. 그래서 개발자와 회계 담당자, 회원가입 담당자가 모두 동일한 정보를 쉽고 빠르게 확인할 수 있도록 하였습니다.

## 3. 실행 및 수정 방법

### 1) 실행 방법 
- 카카오톡 공지기능: 카카오톡 공지 기능은 모임 날짜를 통해서 모임 날짜를 설정할 수 있으며 기본적으로 해당 주의 주말로 설정 되있습니다. 모임 신청 부분에는 모임 신청을 하는 페이지(예시는 앱주소)로 연결되며, 미등록 연락 문의 url은 오픈 카카오톡 주소로 연결 됩니다. 따라서 완성된 공지 전문을 복사하고 발송 대상 오픈 카톡방 주소 열기를 누르면 바로 카카오톡 오픈카톡방으로 연결되어 공지를 보낼 수 있습니다. 또한 실시간 모바일 프리뷰를 통해 어떻게 메시지가 전달될 지 확인 가능합니다. 

- 네이버 카페 공지 기능: 카카오톡 공지와 비슷하게 모임 날짜와 모임 회차 번호가 설정이 가능하며 요일마다 모임 장소가 다르므로 모임 장소도 수정이 가능하게 기능을 추가했습니다. 마찬가지로 완성된 공지 전문을 복사하고 네이버 카페 주소로 바로 이동이 가능하여 공지를 쉽게 할 수 있도록 했습니다. 모임 장소나 회비 템플릿 문구는 app.js 파일에서 손쉽게 수정하여 git push하면 바로 웹에 반영됩니다.

- 독서모임 회원 목록: 회원 목록은 구글 시트를 통해서 실시간으로 확인 할 수 있습니다. 현재 등록된 총 회원 목록을 확인하고 새로운 회원 가입시 바로 구글 시트 바로가기 버튼을 통해 구글 시트로 이동하여 내용을 추가할 수 있도록 했습니다.

- 독서모임 회계 장부: 가입한 회원들이 회비를 납부하면 회계담당자가 회비 내역을 확인하고 회비 납부 목록에 추가한 후 홈페이지에서 바로 확인이 가능하도록 기능을 구현했습니다. 그리고 한달동안 얼마나 많은 회원들이 가입하고 탈퇴했는지 확인 가능하도록 대시보드를 구현했습니다.

## 4. 현재 상태

### 1) 현재 상태에 점검
- 현재 카카오톡은 API로 공지 전송이 불가능한 것을 확인했습니다. 따라서 바로 공지는 불가능해 템플릿을 작성하고 카카오톡 오픈채팅으로 직접 전송해야 하는 방식으로 구현했습니다.


### 2) 동료 의견
- 예전에는 공지를 할때 메모장에 저장된 내용을 수정하고 페이지를 열어 복사 붙여넣기를 하는 방식이었지만 지금은 한 페이지에서 통합적으로 공지를 할 수 있어서 완전 자동화는 아니지만 공지 관리에 도움이 된다고 합니다.

- 회계장부 부분도 총무가 아닌 사람들도 접근해서 확인할 수 있어서 편하게 확인이 가능하다고 합니다. 이전에는 카카오톡으로 총무에게 연락을 해야했지만 지금은 홈페이지에서 확인이 가능하여 편리하다는 의견이 있었습니다.

### 3) 수정 결과
- 기존에는 API를 이용하여 카카오톡 공지 및 네이버 카페 공지를 자동화하려고 했으나 API를 따로 발급 받아야하고 한 페이지에서 통합적으로 관리하는 것만으로도 좋다고 하여 지금 방식으로 구현을 했습니다. 추후 Selenium과 같은 방법으로 자동화하는 방법을 고려하고 있습니다.


### 4) 사용한 자료 및 AI 도움
- 코드와 기능을 구현하는데 도움을 받은 자료는 모두 AI를 활용하여 구현했습니다.

## 5. 상세 기능 안내 (4-Step Workflow)

| 기능 단계 | 주요 명칭 | 핵심 기능 설명 |
| :--- | :--- | :--- |
| **STEP 1** | **💬 카카오톡 공지 자동화** | 이번 주/다음 주 토·일 날짜 원클릭 자동 계산, 노란 말풍선 실시간 모바일 목업, 서식 유지 원클릭 복사 & 카카오톡 앱 바로 연결 |
| **STEP 2** | **📝 네이버 카페 공지 브리지** | 스마트에디터 ONE 서식 실시간 미리보기, `ClipboardItem` 기반 서식+링크 동시 클립보드 복사, 네이버 카페 글쓰기 창 즉시 열기 |
| **STEP 3** | **📊 회원 목록 관리 DB** | 공식 구글 스프레드시트 회원 명단 실시간 연동, 시트 주소 복사, 원본 새 창 열기/편집 연결 |
| **STEP 4** | **💰 회계 장부 & 재정 대시보드** | 누적 잔고(₩100,000), 총 수입, 총 지출, 집행률 4종 KPI 카드, 예산 밸런스 게이지 바, 개인정보 보호 마스킹 입출금 내역 요약 피드, 원본 구글 시트 원클릭 바로가기 |
