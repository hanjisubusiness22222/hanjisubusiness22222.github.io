# BookLink : 독서모임 관리자를 위한 투명한 소통 솔루션

> **기술개발연구프로젝트 2주차: 사전지식과 개인 홈페이지 제작 실습 과제**

---

## 1. 홈페이지 기획 개요

| 기획 질문 | 기획 내용 |
|---|---|
| **누가 내 홈페이지를 볼까요? (방문자)** | **독서모임 관리자들** (북클럽 호스트, 커뮤니티 운영진, 스터디 리더) |
| **그 사람이 나에 대해 무엇을 기억했으면 하나요? (메시지)** | **"투명한 소통"** (운영진과 회원 간의 신뢰 구축, 비대칭 없는 투명한 공지 및 회계/출석 공유) |
| **어떤 소개, 관심 분야, 프로젝트를 다루나요?** | **독서 모임 회원 관리**, 멀티채널 자동화 솔루션, 노코드/로우코드 구글 시트 파이프라인 |
| **방문자가 무엇을 찾으면 목적을 달성한 것인가요? (완료 기준)** | 1) **멀티플랫폼 원클릭 공지 자동화**: 한 곳에서 작성 시 인스타, 소모임, 네이버, 당근, 에타, 카톡 규격으로 동시 배포<br>2) **구글 시트형 실시간 회원 DB**: 관리자가 익숙한 스프레드시트 형태로 회원 명단, 출석률, 회비 납부 현황을 검색·확인 |

## 2. 주요 기능 및 인터랙션

### ① 구글 시트형 실시간 독서모임 회원 DB (`#demo-sheet`)
- **스프레드시트 뷰**: 구글 시트 감성의 직관적인 UI 테이블 (헤더 셀, 상태 뱃지, 실시간 동기화 표시)
- **유입 채널 필터링**: 전체, 소모임, 당근마켓, 인스타그램, 에브리타임, 카카오톡, 네이버 카페 탭별 즉시 필터링
- **실시간 검색**: 회원 이름, 유입 채널, 지정 도서명 검색 지원
- **원클릭 회비 납부 상태 토글**: 클릭 한 번으로 `납부 완료`와 `입금 대기`를 전환하고 전체 납부율 실시간 갱신
- **신규 회원 등록 및 CSV 내보내기**: 폼을 통한 행 추가 및 구글 드라이브/엑셀 호환 CSV 다운로드 지원

### ② 멀티플랫폼 원클릭 공지 자동화 허브 (`#demo-broadcast`)
- **통합 에디터**: 회차 제목, 지정 도서, 모임 일시, 장소, 발제문을 한 화면에서 입력
- **플랫폼별 서식 자동 변환**:
  - **카카오톡**: 알림톡 및 단톡방용 가독성 높은 박스형 서식
  - **소모임**: 정모 투표 독려 및 활동 안내 서식
  - **당근마켓**: 동네 이웃 친화적인 매너온도 강조 서식
  - **인스타그램**: 감성적인 개행 및 자동 해시태그(`#독서모임 #북스타그램 ...`) 생성
  - **에브리타임**: 대학생 북클럽용 깔끔한 공지 서식
- **원클릭 동시 전송 시뮬레이션**: 체크된 채널들에 정보 격차 없이 동시에 배포되는 결과 모달 제공

### ③ '투명한 소통' 3대 가치 섹션 (`#values`)
1. **채널 간 정보 비대칭 제로**: 어느 플랫폼으로 가입했든 소외 없이 동시 공지
2. **누구나 납득하는 데이터 공유**: 출석률, 회비 장부의 맑은 공개
3. **운영진의 과부하 방지**: 자동화로 반복 업무를 줄여 책과 대화에 집중

## 3. 기술 스택 및 구조

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Pretendard Font, CSS 변수 기반 디자인 시스템, Flex/Grid 레이아웃), Vanilla JavaScript (ES6+)
- **접근성(a11y) & 모바일 반응형**:
  - 스킵 링크(`skip-link`) 및 WAI-ARIA 레이블 적용
  - 모바일, 태블릿, 데스크톱 화면에서 가로 스크롤 잘림 없는 유연한 반응형 설계
- **무서버(Serverless) 정적 웹사이트**: GitHub Pages 배포 표준 규격 준수

```text
코드/
├── index.html        # 메인 시맨틱 마크업 및 섹션 구성
├── style.css         # 프리미엄 디자인 시스템, 반응형, 구글시트 테마 CSS
├── app.js            # 회원 DB 인터랙션 및 공지 변환/배포 시뮬레이션
└── README.md         # 프로젝트 기획 및 사용 설명서
```

---

## 4. 로컬 실행 방법

1. 저장소 또는 `코드` 폴더의 [index.html](index.html)을 더블 클릭하여 웹 브라우저(Chrome, Edge, Safari 등)에서 엽니다.
2. 상단 메뉴의 **"회원관리 DB"** 및 **"공지 자동화"** 버튼을 눌러 인터랙티브 기능을 바로 체험할 수 있습니다.
