# BookLink Admin : 독서모임 통합 관리 & 멀티플랫폼 자동화 콘솔

> **기술개발연구프로젝트: 독서모임 관리자 전용 운영 콘솔 웹 애플리케이션**

---

## 1. 프로젝트 개요 및 기획 배경

| 기획 질문 | 기획 내용 |
|---|---|
| **대상 사용자 (Target)** | **독서모임 관리자 / 운영진** (북클럽 호스트, 커뮤니티 리더, 스터디 운영진) |
| **핵심 메시지 (Core Value)** | **"투명한 소통 및 운영 자동화"** (회원 명단과 회비의 투명한 공유, 반복 공지 업무 완전 자동화) |
| **해결하는 핵심 과제** | 1) **구글 시트형 실시간 회원 DB**: 개인정보 익명화(마스킹)와 출석/회비/발제문을 한눈에 관리<br>2) **멀티플랫폼 원클릭 공지 자동화**: 플랫폼별 ID/PW 연동 및 메신저(카카오톡)와 5대 커뮤니티 게시글 분리 배포 |
| **완료 기준** | 관리자가 실제 SaaS처럼 직관적으로 데이터를 관리하고, 한 번의 작성으로 모든 채널에 최적화된 공지를 동시 전송 |

---

## 2. 핵심 기능 상세

### ① 구글 시트형 독서모임 회원 관리 DB
- **정통 구글 스프레드시트 인터페이스**:
  - 파일 제목 수정, 실시간 Google Drive 동기화 인디케이터
  - 메뉴바 (`파일`, `수정`, `보기`, `삽입`, `서식`, `데이터`, `도구`)
  - 서식 툴바 (실행취소/다시실행, 글꼴 크기, 굵게, 기울임, 글자색, 채우기, 정렬, 필터, 함수 Σ)
  - **수식 입력줄 (`fx`)**: 셀 클릭 시 좌표(`B2` 등) 및 값이 연동되며 수식바에서 인라인 편집 지원
- **개인정보 보호 익명 마스킹**:
  - 회원명: 가운데 글자 마스킹 (`이*원`, `박*영`, `최*연` 등)
  - 전화번호: 가운데 4자리 마스킹 (`010-****-8821`, `010-****-3847` 등)
  - 신규 회원 등록 시에도 자동 마스킹 함수가 적용되어 안전하게 저장
- **인터랙티브 회원 관리**:
  - 출석 횟수 즉시 증감 (`-` / `+` 버튼)
  - 회비 납부 상태 원클릭 순환 토글 (`✔ 납부 완료` ➔ `⏳ 입금 대기` ➔ `🏷️ 회비 면제`)
  - 발제문/독서노트 제출 여부 토글 (`✔ 제출 완료` ➔ `⏳ 미제출`)
  - 채널별 필터(소모임, 당근, 인스타, 에타, 카카오톡, 네이버) 및 실시간 다중 검색
  - 다중 선택 체크박스 및 일괄 작업(일괄 납부 완료, 일괄 발제문 제출, 선택 삭제)
  - CSV 다운로드 & JSON 백업 & 데이터 초기화

### ② 멀티플랫폼 원클릭 공지 자동화 (메신저 vs 게시글 분리)
- **🔐 플랫폼별 ID/PW 자동 로그인 & API 인증 계정 설정 (Credentials Manager)**:
  - **💬 메신저 채널 (카카오톡)**: 카카오 계정 ID, 비밀번호/REST API 키, 오픈채팅방 URL, 카톡 봇 세션 연결 상태 및 테스트
  - **📝 게시글 채널 (소모임, 네이버 카페, 당근, 에타, 인스타)**: 각 플랫폼별 ID, 비밀번호, 게시판 카테고리 설정 분리
  - 비밀번호 보기/숨기기(👁️ 토글) 및 자격증명 로컬 안전 저장
- **공지 작성 에디터 & 분기 옵션**:
  - 기본 공통 정보: 모임 회차, 선정 도서, 일시, 장소, 회비, 발제문/전달사항
  - **메신저 전용 옵션**: 단톡방 상단 공지(톡게시판) 핀 고정, 실시간 참석 투표 폼 생성, 전원 멘션
  - **게시글 전용 옵션**: 마크다운 서식 최적화, 북클럽 핵심 해시태그 자동 부여, 구글 시트 투명 공개 링크 첨부
- **실시간 분할 듀얼 프리뷰 (Dual Live Preview)**:
  - **메신저 뷰**: 카카오톡 스마트폰 모바일 목업 (상단바, 톡게시판 핀 바, 노란 말풍선, 참석 투표 버튼)
  - **게시글 뷰**: 탭 전환을 통해 네이버 카페, 소모임 정모, 당근 동네생활, 에타, 인스타그램 등 플랫폼 고유 포스팅 서식 미리보기 지원
- **봇 자동화 실행 터미널 & 리포트 모달**:
  - 원클릭 배포 클릭 시 하단 다크 콘솔에서 ID/PW 인증 ➔ 카톡 알림톡 송신 ➔ 각 게시판 포스팅 등록 로그가 실시간 스트리밍된 후 종합 결과 리포트 모달 표시

## 3. 프로젝트 파일 구조

```text
코드/
├── index.html            # 시맨틱 관리 콘솔 구조 마크업
├── style.css             # SaaS 콘솔, 구글 시트 테마, 카톡 목업, 터미널 스타일
├── app.js                # 회원 DB 수식바/마스킹 로직, 봇 배포 시뮬레이션
├── index_all_in_one.html # 단일 파일 실행/과제 제출용 올인원 통합 HTML
└── README.md             # 프로젝트 기획 및 기능 안내서
```

---

## 4. 실행 방법

1. [index.html](index.html)을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 실행합니다.
2. 단일 파일로 열람할 경우 [index_all_in_one.html](index_all_in_one.html)을 사용할 수 있습니다.
3. 상단 탭(회원 관리 DB / 원클릭 공지 자동화 / 계정 연동 설정)을 통해 모든 기능을 즉시 체험할 수 있습니다.
